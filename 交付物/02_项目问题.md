# 项目问题

## 1. 项目名称

比亚迪财务报表分析智能体

## 2. 要解决的问题

财务初学者阅读比亚迪年度报告时，通常需要在长篇 PDF 中反复查找数据，还要手动计算毛利率、资产负债率和现金流变化，容易出现查找慢、单位混淆、计算错误和来源不可追溯等问题。

本项目使用 Coze 知识库、工作流和计算工具，结合 Streamlit 前端，提供一个能够查询、计算、解释并引用官方财报的问答系统。

## 3. 目标用户

- 财务分析初学者
- 需要快速定位比亚迪财报数据的学生
- 需要复核公式和数据来源的课程评审者

## 4. 成功标准

1. 财报数据能够从知识库检索，并标注文件和页码或明确说明页码未标注。
2. 计算题能够展示公式、代入值和结果。
3. 知识库没有的数据不编造。
4. 对股价预测、买卖建议等超范围问题固定拒答。
5. Coze 输出能够被 Streamlit 解析为 `answer/evidence/calculation/confidence/disclaimer` 五个字段。

## 5. 项目边界

- 默认分析对象为比亚迪（002594.SZ），但前端保留公司名称和股票代码字段，便于扩展其他上市公司。
- 数据范围以已上传的官方定期报告为准。
- 系统只提供教学和财务分析，不提供投资建议、目标价或买卖信号。

## 6. 系统链路

```text
用户问题
  -> Streamlit 页面
  -> Coze API
  -> 意图识别/知识库检索/计算工具/回答生成
  -> 五字段 JSON
  -> Streamlit 解析与渲染
```
