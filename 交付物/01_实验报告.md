# 比亚迪财务报表分析智能体实验报告

> 本文档是可填写版本。凡标记“待填写”的内容，应以实际 Coze 测试、截图和原始记录为准，不应直接编造。

## 1. 实验目标

构建一个面向财务分析初学者的比亚迪财务报表分析智能体，实现财报数据查询、财务比率计算、趋势分析、来源引用、结构化输出和超范围拒答。

具体目标：

1. 配置 Coze 人设、知识库、工具和工作流。
2. 使用官方定期报告作为可追溯数据来源。
3. 通过代码执行器完成财务指标计算。
4. 使用 Streamlit 展示回答、证据、计算过程、置信度和免责声明。
5. 通过评测集验证准确性、可复算性、防幻觉和边界控制。

## 3. 系统设计

### 3.1 人设

角色为“比亚迪财报分析助手”，服务财务分析初学者。回答必须基于已收录的官方财报；涉及计算时调用代码执行器；没有可靠依据时拒答；不提供股价预测、买卖建议和目标价。

### 3.2 知识库

| 材料 | 年份 | 状态 | 清洗与验证 |
|---|---:|---|---|
| 比亚迪年度报告 | 2024 | 待确认 | 正文与三张表分开整理 |
| 比亚迪年度报告 | 2023 | 待确认 | 用于趋势比较 |
| 比亚迪季度/半年度报告 | 待填写 | 待确认 | 仅在实际上传后纳入回答范围 |
| 财务比率公式 QA | - | 待确认 | 一问一答格式 |

建议参数：分段长度 600 字左右、重叠 15%、最大召回 5。

### 3.3 工作流

```text
开始
 -> 意图识别
 -> 财报查询/比率计算/趋势分析/概念解释/超范围分支
 -> 知识库检索
 -> 必要时调用代码执行器
 -> 回答生成
 -> 结束节点 JSON
```

### 3.4 输出协议

```json
{
  "answer": "string",
  "evidence": "string，可为空，多条用；分隔",
  "calculation": "string，无计算时为无",
  "confidence": "高/中/低/未标注",
  "disclaimer": "string，始终显示"
}
```

Coze 可能把上述 JSON 放在 `output` 字符串中，Streamlit 已兼容双层解析。

## 6. 结果解释与反思

待实际测试后填写。建议从以下角度解释：

- 知识库是否提高了财报数据的可追溯性。
- 代码执行器是否降低了手算错误。
- JSON 约束是否减少了前端解析失败。
- 召回数量增加是否带来更多无关内容和更高延迟。

## 7. 局限与展望

- 当前准确性依赖报告是否完整上传、页码是否保留和知识库索引质量。
- 不同报告的科目名称、单位和合并口径可能不同。
- 当前主要面向比亚迪，扩展其他公司时需要重新整理知识库和公司边界。
- 下一步可增加更多报告、自动化评测、结果导出和图表展示。
