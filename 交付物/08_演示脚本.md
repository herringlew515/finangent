# 7分钟答辩演示脚本

## 0:00-0:50：问题与用户

我们面向财务分析初学者，解决“年报数据难查、指标难算、结论难溯源”的问题。系统成功标准是：数据有出处、计算可复算、超范围问题能拒答。

## 0:50-1:50：系统设计

展示 Streamlit 页面和 Coze 工作流。Streamlit 负责输入和渲染，Coze 负责意图识别、知识库检索、计算工具和结构化输出。当前默认对象是比亚迪，但公司字段可扩展。

## 1:50-3:30：正常问答演示

演示 Q01：

```text
比亚迪2024年营业总收入是多少？出自年报第几页？
```

展示 `answer`，展开 `evidence`，回到报告核对文件和页码。

演示 Q02：

```text
计算比亚迪2024年的毛利率。
```

展开 `calculation`，说明公式、营业收入、营业成本、代入值和结果。

## 3:30-4:30：Coze 配置说明

展示人设、知识库、工作流分支和结束节点。结束节点返回五个业务字段：

```text
answer / evidence / calculation / confidence / disclaimer
```

如果结束节点使用 `output` 字符串包装，前端会再解析一层。

## 4:30-5:40：翻车与排查

演示 Q07：

```text
比亚迪2022年第三季度的净利润是多少？
```

说明先检查知识库是否包含该报告，再检查引用内容。如果没有可靠材料，系统应拒答而不是编造数据。展示人机决策日志中的修正记录。

## 5:40-6:30：对照实验

展示 E1 知识库对照、E2 JSON 输出对照和 E3 召回数量对照。填写实际测试数据后，比较引用准确率、JSON 解析成功率、计算复算率和响应时间。

## 6:30-7:00：总结

本项目的重点不是让智能体回答所有问题，而是让它在有依据时准确回答，在需要计算时提供可复算过程，在没有依据或超出范围时明确拒答。

## 演示备用方案

- 断网：准备一次完整演示录屏。
- Token 失效：答辩前重新验证 `.env` 和 Bot 发布版本。
- 工作流超时：使用已保存的正常返回截图，并展示 Coze 预览区结果。
